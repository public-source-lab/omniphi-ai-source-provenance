# OmniPhi Influencer Campaign — Census

## Purpose

This document records individual social-media posts promoting OmniPhi.

The purpose is to determine whether multiple promotional posts share:

- Identical or near-identical wording
- Common hashtags
- Common calls to action
- Common images or videos
- Similar publication timing
- Common links
- Referral or affiliate parameters
- Sponsorship or partner disclosures

The census is intended to document observable evidence, not infer coordination from similarity alone.

## Evidence Standard

Each entry should be supported by at least one of:

- Original post URL
- Archived post URL
- Screenshot
- Search-engine indexed copy
- Other independently preserved evidence

Screenshots should be retained where possible because social-media posts may later be deleted or edited.

## How to Add an Entry

For each post, record:

### Account

Exact username, including punctuation.

### Platform

Instagram, TikTok, YouTube, X, LinkedIn, etc.

### Publication Date

Use the date displayed by the platform.

If the exact time is available, preserve it.

### Campaign Language

Copy only the minimum distinctive wording necessary to demonstrate similarity.

Do not reproduce long copyrighted captions unnecessarily.

### Hashtags

Record:

#omniphipartner

and any other relevant campaign hashtags.

### CTA

Record whether the post asks users to:

- Comment BETA
- Send a DM
- Click a link
- Join a waitlist
- Use a referral code
- Perform another conversion action

### Disclosure

Record exactly what disclosure is visible.

Examples:

- Paid partnership label
- Sponsored
- Advertisement
- Affiliate disclosure
- #ad
- #sponsored
- #omniphipartner
- No visible disclosure

Do not conclude that a disclosure is legally sufficient or insufficient without separately analyzing the applicable legal standard.

### Link

Record the destination URL.

If the URL contains tracking parameters, preserve them exactly.

### Evidence

Record:

- Original post URL
- Screenshot filename
- Archive URL if available
- Search result if applicable

### Status

Use one of:

- Verified
- Partially documented
- Archived
- Deleted but preserved
- Unverified

## Similarity Analysis

Similarity should be evaluated using multiple features.

### Stronger Indicators

- Identical unusual sentence
- Identical image/video
- Identical CTA
- Identical unusual typo
- Identical sequence of claims
- Same publication window
- Same destination/referral link

### Weaker Indicators

- General positive sentiment
- Generic AI terminology
- Common words such as "beta"
- Similar formatting
- Common hashtags alone

## Coordination Assessment

Repeated campaign language can establish that multiple accounts participated in similar promotional messaging.

It does not, by itself, establish:

- Common ownership
- Centralized control
- Payment
- Affiliate compensation
- An agency relationship
- Artificial engagement
- Legal violations

Those conclusions require additional evidence.
